## Why this matters

Your self-model is a function $f(x_t, u_t) \to \hat{x}_{t+1}$: given the arm state and the motor command, predict the next state. For the compliant pendulum the state is a vector $x = [\theta_a, \dot\theta_a]$, and one Euler step of the linearized dynamics is *exactly* a matrix times that vector plus a matrix times the motor angle. A neural forward model has the same structure: matrix, vector, nonlinearity, repeat. When you bumped the mass and got AUC = 0.11, what physically changed was a handful of entries in that matrix. This lesson is about learning to read those entries as a description of the body. By the end you'll have written the forward pass yourself, and you'll see an MLP reproduce your physics model.

## Core ideas

- **A vector is a list you treat as one object.** Your robot's state $x = [\theta_a, \dot\theta_a]$ is a vector; so is a sensor frame, a set of weights, or a batch of predictions.
- **A matrix is a function that eats vectors.** Column $j$ of $M$ is where the $j$-th basis vector lands. So $Mx$ is "take $x_1$ of column 1, plus $x_2$ of column 2, …". That's the *column picture*.
- **The row picture is how you code it.** Entry $i$ of $Mx$ is the dot product of row $i$ with $x$. Two nested loops, nothing more.
- **Shapes first.** $(m \times n)(n \times 1) \to (m \times 1)$. The inner sizes must match. A shape check catches most bugs before you look at any numbers.
- **Multiplication is composition, and order matters.** $AB$ means "do $B$, then $A$". In general $AB \neq BA$.
- **Linear dynamics are a matrix.** Near $\theta = 0$, the pendulum obeys $\dot x = Ax + Bu$. One explicit-Euler step is $x_{t+1} = (I + \Delta t\,A)\,x_t + \Delta t\,B\,u_t$: a matrix-vector product, a scaled vector, and a sum.
- **A neural-net layer is $Wx + b$ followed by a nonlinearity.** Without the nonlinearity, stacking layers collapses into one matrix: $W_2(W_1x + b_1) + b_2 = (W_2W_1)x + (W_2b_1 + b_2)$.
- **Physical parameters live in matrix entries.** Mass, stiffness, and damping show up as specific entries of $A$ and $B$. "Which entries changed?" is a self-modeling question.

## Problem set

<Problem id="p1" kind="concept" title="Columns are where basis vectors land">

Let $M = \begin{bmatrix} 2 & 1 \\ 0 & 3 \end{bmatrix}$. Without multiplying row-by-row, say where $\hat\imath = [1,0]$ and $\hat\jmath = [0,1]$ land, then use that to compute $M\,[1, 2]^\top$.

<Solution>

$\hat\imath \mapsto$ column 1 $= [2, 0]$, and $\hat\jmath \mapsto$ column 2 $= [1, 3]$.
Then $[1,2] = 1\cdot\hat\imath + 2\cdot\hat\jmath \mapsto 1\cdot[2,0] + 2\cdot[1,3] = [4, 6]$.
Row-by-row check: $[2\cdot 1 + 1\cdot 2,\; 0\cdot1 + 3\cdot 2] = [4, 6]$. ✓

</Solution>
</Problem>

<Problem id="p2" kind="compute" title="Shapes and parameter counts">

A forward model takes $z = [\theta_a, \dot\theta_a, \theta_m]$ (3 numbers), has one hidden layer of 16 units, and outputs $[\hat\theta_a, \hat{\dot\theta}_a]$.
(a) What are the shapes of $W_1, b_1, W_2, b_2$? (b) How many parameters in total?

<Solution>

(a) $W_1: 16\times 3$, $b_1: 16$, $W_2: 2 \times 16$, $b_2: 2$.
(b) $48 + 16 + 32 + 2 = 98$ parameters.

</Solution>
</Problem>

<Problem id="p3" kind="compute" title="Order matters">

Let $R = \begin{bmatrix} 0 & -1 \\ 1 & 0 \end{bmatrix}$ (rotate 90°) and $S = \begin{bmatrix} 1 & 1 \\ 0 & 1 \end{bmatrix}$ (shear). Compute $RS$ and $SR$. Describe each in words.

<Solution>

$RS = \begin{bmatrix} 0 & -1 \\ 1 & 1 \end{bmatrix}$: shear first, then rotate.
$SR = \begin{bmatrix} 1 & -1 \\ 1 & 0 \end{bmatrix}$: rotate first, then shear.
They differ, so the order of operations changes the result. In a forward model, "apply the motor, then gravity" vs "gravity, then the motor" can matter in the same way once things stop being linear.

</Solution>
</Problem>

<Problem id="p4" kind="derive" title="Linearize the compliant pendulum">

The arm obeys $I\ddot\theta_a = k(\theta_m - \theta_a) - mgL\sin\theta_a - c\,\dot\theta_a$ with $I = mL^2$.
Using $\sin\theta \approx \theta$, write it as $\dot x = Ax + Bu$ with $x = [\theta_a, \dot\theta_a]^\top$ and $u = \theta_m$.

<Solution>

$\dot\theta_a = \dot\theta_a$ gives row 1: $[0, 1]$. Row 2: $\ddot\theta_a = -\frac{k + mgL}{I}\theta_a - \frac{c}{I}\dot\theta_a + \frac{k}{I}\theta_m$.

$$
A = \begin{bmatrix} 0 & 1 \\ -\dfrac{k + mgL}{I} & -\dfrac{c}{I} \end{bmatrix}, \qquad
B = \begin{bmatrix} 0 \\ \dfrac{k}{I} \end{bmatrix}.
$$

Note that gravity adds to the spring stiffness: the effective stiffness is $k + mgL$, not $k$.

</Solution>
</Problem>

<Problem id="p5" kind="compute" title="One Euler step by hand">

With $m = 1$ kg, $L = 1$ m, $k = 10$ N·m/rad, $c = 0.1$ N·m·s/rad, $g = 9.81$, $\Delta t = 0.01$ s: compute $A_d = I + \Delta t A$ and $B_d = \Delta t B$. Then predict $x_{t+1}$ from $x_t = [0.1, 0]$ and $u_t = 0.3$ rad.

<Solution>

$I = 1$, so $A = \begin{bmatrix} 0 & 1 \\ -19.81 & -0.1\end{bmatrix}$ and $B = [0, 10]^\top$.

$A_d = \begin{bmatrix} 1 & 0.01 \\ -0.1981 & 0.999 \end{bmatrix}$, $B_d = [0, 0.1]^\top$.

$x_{t+1} = [\,0.1 + 0.01\cdot 0,\; -0.1981\cdot 0.1 + 0.999\cdot 0 + 0.1\cdot 0.3\,] = [0.1,\; 0.01019]$.

The angle doesn't move in one step (velocity was zero), but the spring is already accelerating the arm toward $\theta_m$.

</Solution>
</Problem>

<Problem id="p6" kind="concept" title="Why a linear network can't learn gravity">

Show that a two-layer network with *no* activation function is equivalent to a single layer. What does that imply about learning the pendulum at large swing angles?

<Solution>

$W_2(W_1 z + b_1) + b_2 = (W_2 W_1) z + (W_2 b_1 + b_2) = W' z + b'$. Any depth collapses to one affine map.
At large angles the gravity torque is $mgL\sin\theta_a$, which isn't linear in $\theta_a$. A purely linear model can only fit the best straight-line approximation and will be wrong at big swings. Nonlinearities like tanh are what let a network bend to fit $\sin\theta$.

</Solution>
</Problem>

<Problem id="p7" kind="compute" title="The mass bump, as matrix entries">

Using the defaults from Problem 5, bump the mass to $1.5$ kg. Recompute the entries of $A$ and $B$ that change. Which entries change by the largest *fraction*? Which term is unaffected?

<Solution>

$I = 1.5$. $A_{21} = -(10 + 1.5\cdot 9.81)/1.5 = -(k/I + g/L) = -(6.667 + 9.81) = -16.48$ (was $-19.81$: about $-17\%$).
$A_{22} = -0.1/1.5 = -0.0667$ (was $-0.1$: $-33\%$). $B_2 = 10/1.5 = 6.667$ (was $10$: $-33\%$).

The $g/L$ part of $A_{21}$ doesn't change at all, because mass cancels out of gravity's effect on angular acceleration. Mass only shows up through the spring ($k/I$) and damping ($c/I$) terms. Keep this in mind: it's why the natural frequency drops less than you might expect.

</Solution>
</Problem>

<Problem id="p8" kind="estimate" title="How expensive is a forward pass?">

Count the multiplies in one forward pass of a $3 \to 64 \to 64 \to 2$ MLP (ignore biases and activations). At a 500 Hz control rate, how many multiplies per second is that?

<Solution>

$3\cdot64 + 64\cdot64 + 64\cdot2 = 192 + 4096 + 128 = 4416$ multiplies per pass.
At 500 Hz that's about $2.2 \times 10^6$ per second, which is trivial for any CPU. Forward models are cheap to *run*. Getting the data and fitting them is the hard part.

</Solution>
</Problem>
