<Article id="brief" title="The brief">

**Research question.** When a robot fits its own body parameters by differentiating through a simulator, how do rollout length, noise and initial guess decide whether it converges, and how does that compare with the closed-form least squares from A1?

**Why a lab cares.** Differentiable simulation (MuJoCo **MJX**, Brax, JAX-based world models) is how many teams calibrate sim-to-real and train models end to end. Its failure modes are well known to practitioners and badly documented: exploding gradients over long rollouts, local minima from oscillation, noise sensitivity. A crisp empirical map of those failure modes on a system you fully understand is genuinely useful.

**What you'll build.**
1. The compliant pendulum's semi-implicit Euler step in **JAX**, checked against MuJoCo for the same parameters.
2. Gradients of a trajectory loss with respect to $(m, k, c)$ three ways: finite differences, `jax.grad` and your own dual-number code from A2. Show that they agree.
3. Gradient-based fitting with Optax (Adam) and Gauss–Newton, from many initial guesses.
4. A map of the loss landscape vs. rollout horizon: when do gradients explode, and when does the fit lock onto the wrong oscillation?
5. Comparison with the A1 least-squares estimator: accuracy, data needed, and robustness to noise.

**Deliverables.** A repo plus a 4-page paper.

</Article>

```python
import jax, jax.numpy as jnp
def step(state, u, p, dt=0.002):
    th, w = state
    I = p["m"] * p["L"]**2
    acc = (p["k"]*(u - th) - p["m"]*9.81*p["L"]*jnp.sin(th) - p["c"]*w) / I
    w = w + dt*acc
    return (th + dt*w, w)
def rollout(p, us):
    def f(s, u): s = step(s, u, p); return s, s[0]
    return jax.lax.scan(f, (0.0, 0.0), us)[1]
loss = lambda p, us, y: jnp.mean((rollout(p, us) - y)**2)
grads = jax.grad(loss)(params, us, measured)
```
